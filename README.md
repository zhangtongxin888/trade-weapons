# Trade Weapons Wiki

Independent, source-checked guide site for the Roblox experience Trade Weapons.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run check
```

The production build is a static export in `out/`. The official site domain is `https://tradeweapons.wiki`.

Research and launch evidence live under `.launch/`. Do not publish gameplay claims unless their fact IDs are approved in `.launch/research/research-approved.json`.
